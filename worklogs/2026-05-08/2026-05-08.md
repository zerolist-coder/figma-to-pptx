## 1. 오늘 반영한 수정 요약

### 1.1 삼각형 회전 (Figma 플러그인)

- **증상:** PPT 대비 삼각형 회전이 어긋나 보임.
- **원인:** OOXML `triangle` 프리셋은 **꼭짓점 위·밑변 아래**로, 플러그인의 벡터 삼각형 경로와 방향이 동일함에도 삼각형만 `+rotation`을 적용해 Y축 보정이 맞지 않음.
- **조치:** 삼각형 포함 모든 도형에 **`-rotation`** 통일 (`flipHorizontal` XOR `flipVertical` 시 부호 반전 규칙 유지).
- **파일:** `plugin/src/plugin/main.ts` — `figmaRotationFromPpt`

### 1.2 오른쪽 블록 화살표(RIGHT_ARROW) 기하

- **증상:** PPT의 오른쪽 화살표와 형태가 다름 (노란 점선 테두리는 유지 가능하나 **본체·머리 비율**이 잘못 매핑됨).
- **원인:** `adj1`/`adj2`를 임의 비율로 해석함. DrawingML `rightArrow`는 ISO 프리셋 수식과 다름.
- **조치:** DrawingML `presetShapeDefinitions`의 `rightArrow` 정의와 동일하게 계산:
  - `ss = min(w, h)`, `maxAdj2 = 100000 * w / ss`
  - `a1`, `a2` 클램프 후 `dx1`, `x1`, `dy1`, `y1`, `y2`, 꼭짓점 순서의 폴리곤 경로 생성
  - 조정값 기본: 각 `50000` (XML에 없을 때)
- **파일:** `plugin/src/plugin/main.ts` — `createRightArrow`

### 1.3 빌드/로그 태그

- 파이프라인 식별용 리비전을 **3**으로 증가 (Eclipse 콘솔·UI 태그 일치).
- **파일:**

  - `plugin/src/constants/import-build.ts` — `IMPORT_REVISION = 3`
